# Code of Conduct

This project follows the [Contributor Covenant, version 2.1][covenant]. The full text is on the
Covenant's own site and is not copied here; by taking part you agree to it.

It applies everywhere the project is run: issues, pull requests, discussions, review comments
and anything else in this repository, and to anyone who represents the project elsewhere.

## Reporting a problem

The maintainer, [problem-xyz](https://github.com/problem-xyz), enforces the Code of Conduct and
handles every report following the Covenant's enforcement guidelines.

- **Anything sensitive** (harassment, personal attacks, anything you would not want to discuss
  in public) goes in privately, through the repository's **Security** tab: press **Report a
  vulnerability**, or open the [private report form][private], and start the title with
  "Conduct:". It is the private channel [`SECURITY.md`](SECURITY.md) describes, and only you and
  the maintainer can see what you write there.
- **Non-sensitive matters**, such as a question about what the rules allow, can go in an
  ordinary [GitHub issue][issues].

Reports are kept confidential. If the problem involves the maintainer, or you would rather not
report to the project at all, GitHub's own [abuse report form][abuse] reaches GitHub staff
directly.
